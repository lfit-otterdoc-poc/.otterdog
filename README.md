# .otterdog

[Otterdog](https://github.com/eclipse-csi/otterdog) settings for the
`lfit-otterdoc-poc` GitHub organization: org settings, teams, repos and
branch rules, as code.

To change a setting, open a pull request against
`otterdog/lfit-otterdoc-poc.jsonnet`. The Otterdog webapp posts a plan
of what would change. When the pull request merges, it applies the
change to GitHub.

The LF-wide defaults this file builds on live in
[`otterdog-config`](https://github.com/lfit-otterdoc-poc/otterdog-config).

## Status
